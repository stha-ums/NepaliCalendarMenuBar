BS Calendar

A beautiful, lightweight Nepali calendar for your macOS menu bar.

Download on App Store GitHub Release

Features

Dual Calendar System

Support for both Bikram Sambat (BS) and Gregorian calendars (2000-2100 BS).

Multi-Language

English and Nepali (नेपाली) support with proper numerals and localization.

Calendar Integration

View your macOS Calendar events directly within the Nepali date context.

Beautiful Views

Switch between a monthly grid view and a schedule timeline for your upcoming events.

Privacy First

Date conversions happen locally. Anonymous telemetry helps us improve without tracking you.

Native & Fast

Built as a native macOS menu bar app. Lightweight, fast, and stays out of your way.
